API

创建实例

new AnimeCursor(options)

创建一个新的 AnimeCursor 实例，并立即初始化光标行为。

AnimeCursor 实例最多只允许存在一个。

当你尝试初始化第二个 AnimeCursor 实例时，控制台会显示一个warning。并且该初始化不会继续进行。

refresh

AnimeCursor.refresh()

refresh() 用于在 页面 DOM 发生变化后，重新扫描并应用光标规则到新增元素。

AnimeCursor 在初始化时只会在 DOM 加载完成后扫描一次 DOM。如果你的部分页面内容是在 DOM 加载完成后动态插入的（例如 Markdown 渲染、Ajax 加载、SPA 路由切换），你必须在内容插入完成后手动调用 refresh()。

示例

// 假设页面使用 marked 加载外部 markdown 文件并注入渲染完成的 DOM
fetch('markdown.md')
    .then(res => res.text())
    .then(html => {
        container.innerHTML = html;
        AnimeCursor.refresh();
});

disable / enable

AnimeCursor.disable()
AnimeCursor.enable()

  • disable()：暂时隐藏并停用光标效果（不销毁实例）

  • enable()：重新启用光标效果

适用于临时场景切换（例如进入表单区域、弹窗等）。

destroy

AnimeCursor.destroy()

彻底销毁 AnimeCursor 实例，包括：

  • 移除注入的 DOM 元素

  • 移除注入的 CSS

  • 移除事件监听

  • 清理 data-cursor 标记

调用 destroy() 后，该实例不可再复用。
