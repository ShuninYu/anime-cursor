debug 模式

启用 debug 模式

new AnimeCursor({
    debug: true,
    cursors: {...}
});

debug 模式会显示：

  • 当前鼠标坐标

  • 当前光标类型

  • 光标边界

debug 模式主要可以用来校准光标、测试切换、检查光标尺寸。

常见问题

光标不显示 / 没有变化

  • 检查图片路径

  • 检查光标设置是否合法，检查控制台是否有报错

  • 检查 tags 是否匹配元素

  • 是否在 DOM 插入后调用 refresh()

  • 是否调用过 destroy()

第一次切换到新的光标时，光标会消失一下

  • 检查是否是在 DOM 加载完成后才 new AnimeCursor() 实例化 AnimeCursor。
    AnimeCursor 会在 DOM 加载完成前在页面插入光标图片的预加载标签，如果在 DOM 加载完成后才加载图片，有可能因为图片文件尺寸产生加载延迟，导致切换光标时光标图片还未加载好，引发光标的短暂消失。

  • 尝试压缩你的图片，尤其是大尺寸的 PNG 精灵图表。在质量差距不大的情况下，压缩成 WEBP 格式的图片的文件尺寸要比未被压缩的 PNG 图片小得多，这也能够帮助光标图片提升加载速度。

[已知问题] 在使用 liveserver 和 Firefox 测试页面的时候，即使配置正确且没有报错，也会偶尔出现默认光标不显示的问题，但是使用 Firefox 浏览实际部署的页面时不会出现该问题。暂时没有找到问题原因。
