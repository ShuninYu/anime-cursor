API

Creating an Instance

new AnimeCursor(options)

Creates a new AnimeCursor instance and immediately initializes cursor behavior.

There can be only one AnimeCursor instance at a time.

You will get a warning in the console if you try to initialize a second AnimeCursor. The initialization will not proceed.

refresh

AnimeCursor.refresh()

refresh() re‑scans the page, regenerates CSS rules, and applies cursor definitions to any newly added elements. Use this after dynamic DOM changes (e.g., AJAX content, Markdown rendering, SPA route changes).

Example

fetch('markdown.md')
    .then(res => res.text())
    .then(html => {
        container.innerHTML = html;
        AnimeCursor.refresh();
});

disable / enable

AnimeCursor.disable()
AnimeCursor.enable()

  • disable(): Temporarily disables the custom cursor, restoring the system cursor (without destroying the instance).

  • enable(): Re‑enables the custom cursor.

Useful for temporary context switches (e.g., entering a form area, opening a modal).

destroy

AnimeCursor.destroy()

Completely destroys the AnimeCursor instance, including:

  • Removing injected CSS rules.

  • Removing the debug overlay if active.

  • Removing event listeners (mousemove for debug).

  • Clearing the global disabled class.

The instance cannot be reused after calling destroy().
