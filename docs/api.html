API

Creating an Instance

new AnimeCursor(options)

Creates a new AnimeCursor instance and immediately initializes cursor behavior.

refresh

cursor.refresh(): void

refresh() is used to re-scan the page and apply cursor rules to newly added elements after the DOM has changed.

AnimeCursor only scans the DOM once during initialization. If your page content is dynamically inserted (e.g., Markdown rendering, Ajax loading, SPA route changes), you must manually call refresh() after the content insertion is complete.

Example

// Assuming the page uses 'marked' to load an external markdown file and injects the rendered DOM
fetch('content.md')
    .then(res => res.text())
    .then(html => {
        container.innerHTML = html;
        cursor.refresh();
});

enable / disable

cursor.disable(): void
cursor.enable(): void

  • disable(): Temporarily hides and deactivates the cursor effect (without destroying the instance).

  • enable(): Re-enables the cursor effect.

Suitable for temporary context switching (e.g., entering a form area, opening a modal, etc.).

destroy

cursor.destroy(): void

Completely destroys the AnimeCursor instance, including:

  • Removing injected DOM elements.

  • Removing injected CSS.

  • Removing event listeners.

  • Cleaning up data-cursor markers.

The instance cannot be reused after calling destroy().
