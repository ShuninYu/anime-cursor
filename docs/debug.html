Debugging & Troubleshooting

Debug Mode

Enable debug mode

new AnimeCursor({
    debug: true,
    cursors: {...}
});

Debug mode will display:

  • Current mouse coordinates

  • Current cursor type

  • Cursor boundaries

Debug mode is primarily useful for calibrating the cursor, testing switching behavior, and checking cursor dimensions.

Common Issues

Cursor not showing / No change

  • Check the image path.

  • Check if cursor settings are valid and see if there are any errors in the console.

  • Check if tags match the intended elements.

  • Check if refresh() was called after DOM insertion.

  • Check if destroy() was called.

The cursor briefly disappears when switching to a new cursor for the first time

  • Check if new AnimeCursor() is instantiated only after the DOM has finished loading.
    AnimeCursor inserts preload tags for cursor images into the page before the DOM finishes loading. If images are loaded after DOM completion, loading delays may occur due to image file sizes, causing the cursor image to not be ready when switching and resulting in a brief disappearance of the cursor.

  • Try compressing your images, especially large-sized PNG sprite sheets. When the quality difference is minimal, images compressed into the WEBP format are significantly smaller in file size compared to uncompressed PNG images, which can also help improve the loading speed of cursor images.

[Known Issue] When testing a page with live server and Firefox, the default cursor may occasionally fail to display even with correct configuration and no console errors. However, this issue does not occur when viewing the actually deployed page with Firefox. The root cause is currently unknown.
