开始使用

安装

  1. 准备光标图片

    AnimeCursor v2 使用 独立帧图片（而非精灵图表）。你需要为每个动画光标准备一组图片，文件名包含数字序号。第一帧必须包含数字（例如 cursor_01.png），库会自动识别模式并生成后续帧的 URL。

    支持的文件名格式：

    • cursor_001.png → cursor_002.png → cursor_003.png
    • cursor(01).png → cursor(02).png → cursor(03).png
    • cursor[1].png → cursor[2].png → cursor[3].png
    • cursor_1.png → cursor_2.png → cursor_3.png（无前导零）

    如果没有找到数字，库会自动添加 _%d（例如 cursor.png → cursor_1.png）。所有帧的尺寸必须相同；光标实际大小即为图片原始尺寸，如需缩放请预先处理图片。

    静态光标（单张图片）同样支持——只需省略 frames 和 duration 即可。

  2. 部署 AnimeCursor

    • CDN

      <script src="https://cdn.jsdelivr.net/npm/anime-cursor@2/dist/anime-cursor.umd.min.js"></script>

    • npm

      npm i anime-cursor@2
      import AnimeCursor from 'anime-cursor';
new AnimeCursor({...});

    • 本地部署

      <script src="anime-cursor.umd.min.js"></script>

基本用法

初始化 AnimeCursor：

new AnimeCursor({
    // 配置区域
});

你可以在 DOM 加载完成前初始化 AnimeCursor。避免将 new AnimeCursor() 放在 DOMContentLoaded 回调中，因为预加载机制在库早期加载时效果最好。

在 cursors 中定义光标：

cursors: {
    cursorTypeOne: { /* 参数 */ },
    cursorTypeTwo: { /* 参数 */ }
}

每个光标必须包含 image（第一帧），如需动画还需 frames 和 duration。使用 tags 自动将光标应用到指定 HTML 元素，或手动为元素添加 data-cursor="光标类型"。

示例

一个最小可运行示例：

new AnimeCursor({
    cursors: {
        default: {
            image: '/cursor/default.png',
            default: true
        },
        pointer: {
            tags: ['a', 'button'],
            image: '/cursor/pointer_001.png',
            frames: 4,
            duration: 0.4,
            offset: [15, 25],
            pingpong: true
        },
        text: {
            tags: ['p', 'h1', 'h2', 'span'],
            image: '/cursor/text.png'  // 静态光标
        }
    }
});

这个例子中：

  • default 光标（静态）在无其他匹配时使用。
  • pointer 是动画光标，4 帧（匀速）并启用乒乓循环。
  • text 是静态光标，应用于文本元素。

你也可以使用数组实现变速动画：

pointer: {
    tags: ['a', 'button'],
    image: '/cursor/pointer_01.png',
    frames: [2, 3],      // 前2帧，后3帧
    duration: [0.2, 1.0], // 总时长1.2秒
    offset: [15, 25]
}

从 v1 升级

AnimeCursor v2 是完全重写的版本。如果你是从 v1 升级，请注意：

  • 不再支持精灵图表 – 请将精灵图表拆分成独立帧图片。后续可能提供辅助工具。
  • 已移除的配置项：size、scale、pixel、zindex、displayOnLoad。光标尺寸现在由图片本身决定。
  • 新增配置项：全局的 fallbackCursor、excludeSelectors，每个光标可单独设置 fallback。
  • 默认光标可选 – 可以省略默认光标，未匹配的元素将使用系统光标。
  • 动画节奏 现在支持数组形式的变速动画。

大多数项目迁移很简单：将精灵图拆分为带序号的独立帧，移除已弃用配置，测试即可。
