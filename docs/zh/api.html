API

创建实例

new AnimeCursor(options)

创建一个新的 AnimeCursor 实例，并立即初始化光标行为。

AnimeCursor 实例最多只允许存在一个。

当你尝试初始化第二个 AnimeCursor 实例时，控制台会显示一个警告，且初始化不会继续进行。

refresh

AnimeCursor.refresh()

refresh() 用于重新扫描页面，重新生成 CSS 规则，并将光标定义应用到新增的元素上。在动态 DOM 变化后（如 AJAX 内容、Markdown 渲染、SPA 路由切换）调用此方法。

示例

fetch('markdown.md')
    .then(res => res.text())
    .then(html => {
        container.innerHTML = html;
        AnimeCursor.refresh();
});

disable / enable

AnimeCursor.disable()
AnimeCursor.enable()

  • disable()：暂时禁用自定义光标，恢复系统光标（不销毁实例）。

  • enable()：重新启用自定义光标。

适用于临时场景切换（例如进入表单区域、打开弹窗等）。

destroy

AnimeCursor.destroy()

彻底销毁 AnimeCursor 实例，包括：

  • 移除注入的 CSS 规则。

  • 移除调试浮层（如果激活）。

  • 移除事件监听（调试模式下的鼠标移动监听）。

  • 清除全局禁用类。

调用 destroy() 后，该实例不可再复用。
