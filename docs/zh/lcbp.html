Lifecycle & Best Practices

DOM 注入时机

由于 AnimeCursor 需要在 HTML 中插入 preload 以预加载光标图片，所以请避免在 DOM 加载完成后创建 AnimeCursor 实例。

另外，在创建 AnimeCursor 实例后，如果有动态插入的 DOM，那么这些 DOM 会缺少 data-cursor，而 AnimeCursor 依赖 data-cursor 来判断光标切换。但是没关系，AnimeCursor 提供了解决这类问题的 API。

❌错误示例：

new AnimeCursor();
fetchMarkdown();

✅正确示例：

fetchMarkdown().then(() => {
    new AnimeCursor();
});

或

const cursor = new AnimeCursor();
fetchMarkdown().then(() => cursor.refresh());

配合 Markdown / SPA 使用

  • Markdown 渲染完成后调用 refresh()

  • SPA 路由切换后调用 refresh()

  • 不要在每次更新时重新 new AnimeCursor()
