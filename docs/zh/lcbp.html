生命周期与最佳实践

DOM 注入时机

AnimeCursor v2 不会注入任何 DOM 元素（可选的调试浮层除外），因此对实例创建时机没有严格限制。但为了尽早预加载图片，建议尽可能早地初始化 AnimeCursor，最好在 DOM 加载完成前。

如果你动态添加了新内容（例如通过 AJAX、Markdown 渲染、SPA 路由切换），请在内容插入后调用 refresh()。这会重新生成 CSS 规则，并将光标定义应用到新元素上。

❌错误示例：

new AnimeCursor();
fetchMarkdown(); // 插入后未调用 refresh()

✅正确示例：

fetchMarkdown().then(() => {
    new AnimeCursor(); // 也可，但更推荐提前初始化并刷新
});

或

const cursor = new AnimeCursor();
fetchMarkdown().then(() => cursor.refresh());

配合 Markdown / SPA 使用

  • Markdown 渲染完成后调用 refresh()

  • SPA 路由切换后调用 refresh()

  • 不要在每次更新时重新创建实例——复用已有实例，调用 refresh() 即可。

性能提示

  • AnimeCursor v2 仅使用 CSS，没有持续的 JavaScript 监听（调试模式除外），开箱即用性能极佳。

  • 即使定义多种光标类型，生成的 CSS 规则也很轻量，由浏览器高效应用。

  • 使用 excludeSelectors 避免覆盖输入框的原生文本光标，提升可用性。
