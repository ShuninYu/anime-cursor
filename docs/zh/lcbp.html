Lifecycle & Best Practices

DOM 注入时机

由于 AnimeCursor 需要向 DOM 注入 data-cursor，所以请在 DOM 加载完成后创建 AnimeCursor 实例。如果在 DOM 加载完成前创建 AnimeCursor 实例，可能导致部分 DOM 元素缺少 data-cursor，从而影响光标切换。

同样的，即使在 DOM 加载完成后创建 AnimeCursor 实例，如果有动态插入的 DOM，那么这些 DOM 也会缺少 data-cursor，而 AnimeCursor 提供了对应的解决这类问题的 API。

❌错误示例：

new AnimeCursor();
fetchMarkdown();

✅正确示例：

fetchMarkdown().then(() => {
    new AnimeCursor();
});

或

const cursor = new AnimeCursor();
fetchMarkdown().then(() => cursor.refresh());

配合 Markdown / SPA 使用

  • Markdown 渲染完成后调用 refresh()

  • SPA 路由切换后调用 refresh()

  • 不要在每次更新时重新 new AnimeCursor()
