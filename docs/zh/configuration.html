配置

光标类型

cursors 是 AnimeCursor 的核心配置项。每一个 key 表示一种光标类型，名称可自由定义。

cursors: {
    default: { ... },
    pointer: { ... },
    text: { ... }
}

参数选项

参数详细介绍

  • image

    必填项。指向第一帧图片。AnimeCursor 会查找文件名中的数字后缀（如 cursor_01.png），并自动递增该数字（保留格式）生成后续帧的 URL。如果没有找到数字，库会添加 _%d（例如 cursor.png → cursor_1.png）。

    所有帧的图片尺寸必须相同。光标实际大小即为图片原始尺寸，如需缩放请预先处理好图片。

  • frames / duration

    这两个参数共同定义动画。它们可以是：

    • 两者均为数字：匀速动画。例如 frames: 4, duration: 0.4 → 4 帧，每帧显示 0.1 秒。
    • 两者均为等长数组：变速动画。例如 frames: [2,3], duration: [0.2,1.0] → 前 2 帧在 0.2 秒内播放，后 3 帧在 1.0 秒内播放。

    如果只设置了其中一个，或参数无效（如非正数、数组长度不匹配），光标将被视为静态，并在控制台输出警告。

  • tags

    可选。HTML 标签名数组（如 ['a','button']）。初始化/刷新时，AnimeCursor 会生成 CSS 规则，将这些标签自动应用该光标。如果省略，该光标只能通过手动添加 data-cursor="光标名" 来触发。

    标签名全局唯一——同一个标签不能分配给两个不同的光标。

  • default

    可选。设置为 true 时，该光标成为默认光标。当鼠标下方元素无其他光标匹配时使用。最多只能有一个默认光标。如果未定义，未匹配的元素将使用系统光标。

  • offset

    可选。指定热点偏移 [x, y] 像素，对应 cursor: url(...) x y 语法。默认 [0,0]（左上角）。

  • pingpong

    可选。若为 true，动画交替方向播放（正向 → 反向 → 正向…）。默认 false（始终正向）。

  • fallback

    可选。备用光标类型（如 'auto'、'pointer'），用于当自定义图片加载失败或不支持时。会覆盖全局 fallbackCursor。

  • combineAnimations

    全局选项，默认 false。当设为 true 时，AnimeCursor 会查找所有带有 data-ac-animation 属性的元素，并自动确定每个元素对应的光标类型（通过 tags 或 data-cursor），然后生成组合 CSS 规则，将光标动画与用户定义的动画合并，避免覆盖。

    示例：

    <button data-ac-animation="mySpin 2s linear infinite">点我</button>

    注意：元素必须能够匹配某个光标（通过 tags 或 data-cursor），组合动画才会生效。

全局选项

全局选项与 cursors 同级。

选项类型默认值描述
combineAnimations boolean false 自动将光标动画与元素自身定义的动画（通过 data-ac-animation）合并。开启后，任何带有 data-ac-animation 属性的元素，其光标动画与用户动画会同时播放，互不覆盖。
debugbooleanfalse启用调试浮层，显示当前光标类型和坐标（会启用轻量级鼠标监听）。
fallbackCursorstring'auto'全局备用光标类型（如 'auto', 'pointer'）。
excludeSelectorsstring'input, textarea, [contenteditable]'始终使用原生文本光标的 CSS 选择器（防止覆盖文本输入框）。
enableTouchbooleanfalse在触屏设备上启用动画光标（默认禁用，因为触屏行为不同）。
