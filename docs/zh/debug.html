调试与故障排除

debug 模式

启用 debug 模式

new AnimeCursor({
    debug: true,
    cursors: {...}
});

debug 模式会显示：

  • 当前鼠标坐标

  • 当前光标类型（若无自定义光标匹配则显示 "native"）

debug 模式主要可以用来校准热点偏移、测试光标切换、验证帧图片是否正常加载。

常见问题

光标不显示 / 没有变化

  • 检查图片路径 – 确保第一帧存在，且命名模式正确。

  • 如果使用动画光标，确认 frames 和 duration 均已设置且有效（数字或数组）。检查控制台警告。

  • 检查 tags 是否匹配目标元素，或是否已为元素正确设置 data-cursor。

  • 动态 DOM 变化后是否调用了 refresh()？

  • 是否意外调用了 destroy()？

动画不播放 / 播放异常

  • 确保 frames 和 duration 均已设置且有效。

  • 对于变速动画，确保两者均为等长数组且包含正数。

  • 所有帧图片必须存在于自动生成的 URL 中。检查网络面板是否有 404 错误。

第一次切换到新的光标时，光标会消失一下

  • 图片可能尚未完全加载。预加载标签虽已提前插入，但大图仍可能导致短暂延迟。考虑压缩图片。

  • 确保 AnimeCursor 在 DOM 加载完成前初始化（不要放在 DOMContentLoaded 回调内）。

[已知问题] 在使用 live server 和 Firefox 测试页面时，即使配置正确且没有报错，也会偶尔出现默认光标不显示的问题，但使用 Firefox 浏览实际部署的页面时不会出现该问题。暂时没有找到问题原因。
