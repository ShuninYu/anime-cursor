Lifecycle & Best Practices

DOM Injection Timing

Since AnimeCursor needs to inject data-cursor into the DOM, please create the AnimeCursor instance after the DOM has fully loaded. Creating the AnimeCursor instance before the DOM is ready may cause some DOM elements to lack the data-cursor attribute, which can affect cursor switching.

Similarly, even if the AnimeCursor instance is created after the DOM loads, any dynamically inserted DOM elements will also lack the data-cursor attribute. AnimeCursor provides corresponding APIs to address such issues.

❌ Incorrect example:

new AnimeCursor();
fetchMarkdown();

✅ Correct examples:

fetchMarkdown().then(() => {
    new AnimeCursor();
});

Or

const cursor = new AnimeCursor();
fetchMarkdown().then(() => cursor.refresh());

Usage with Markdown / SPA

  • Call refresh() after Markdown rendering is complete.

  • Call refresh() after SPA route changes.

  • Avoid creating a new AnimeCursor() instance on every update.
