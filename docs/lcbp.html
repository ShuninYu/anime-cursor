Lifecycle & Best Practices

DOM Injection Timing

Since AnimeCursor needs to insert preload tags into the HTML to preload cursor images, avoid creating the AnimeCursor instance after the DOM has finished loading.

Besides, if any DOM elements are dynamically inserted after the AnimeCursor instance is created, they will lack the data-cursor attribute. AnimeCursor relies on data-cursor to determine cursor switching. However, this is not a problem because AnimeCursor provides APIs to handle such situations.

❌ Incorrect example:

new AnimeCursor();
fetchMarkdown();

✅ Correct examples:

fetchMarkdown().then(() => {
    new AnimeCursor();
});

Or

const cursor = new AnimeCursor();
fetchMarkdown().then(() => cursor.refresh());

Usage with Markdown / SPA

  • Call refresh() after Markdown rendering is complete.

  • Call refresh() after SPA route changes.

  • Avoid creating a new AnimeCursor() instance on every update.
