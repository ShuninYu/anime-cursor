Configuration

Cursor Types

cursors is the core configuration option. Each key represents a cursor type. You are free to name them.

cursors: {
    default: { ... },
    pointer: { ... },
    text: { ... }
}

Parameter Details

  • image

    Required. Points to the first frame image. AnimeCursor will look for a numeric suffix (e.g., cursor_01.png) and automatically generate URLs for subsequent frames by incrementing the number while preserving formatting (leading zeros, parentheses, brackets). If no number is found, the library appends _%d (e.g., cursor.png → cursor_1.png).

    All frames must be the same size. The actual cursor size is the natural image size – scale images beforehand if needed.

  • frames / duration

    These two parameters together define the animation. They can be:

    • Both numbers: uniform animation. Example: frames: 4, duration: 0.4 → 4 frames, each displayed for 0.1s.
    • Both arrays of equal length: variable‑speed animation. Example: frames: [2,3], duration: [0.2,1.0] → first 2 frames in 0.2s, then 3 frames in 1.0s.

    If only one of them is set, or if they are invalid (e.g., non‑positive numbers, mismatched array lengths), the cursor is treated as static and a warning is logged.

  • tags

    Optional. An array of HTML tag names (e.g., ['a','button']). During initialization/refresh, AnimeCursor will generate CSS rules to apply this cursor to those tags. If omitted, the cursor can only be triggered by manually adding data-cursor="cursorName" to elements.

    Tag names are globally unique – the same tag cannot be assigned to two different cursors.

  • default

    Optional. When set to true, this cursor becomes the default. It is used when no other cursor matches the element under the mouse. At most one cursor can be default. If none is defined, elements without a matching cursor will use the system cursor.

  • offset

    Optional. Specifies the hotspot offset [x, y] in pixels. This corresponds to the cursor: url(...) x y syntax. Default: [0,0] (top‑left corner).

  • pingpong

    Optional. If true, the animation alternates direction (forward, backward, forward…). Default: false (always forward).

  • fallback

    Optional. A fallback cursor type (e.g., 'auto', 'pointer') to use if the custom image fails to load or is not supported. Overrides the global fallbackCursor for this cursor.

Global Options

Global options are placed at the same level as cursors.

OptionTypeDefaultDescription
debugbooleanfalseEnables a debug overlay showing current cursor type and coordinates (uses a lightweight mousemove listener).
